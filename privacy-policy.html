《武侠重开模拟器》隐私政策

更新日期：2026年9月23日

生效日期：2026年9月23日

欢迎使用《武侠重开模拟器》（游戏内显示名称为《武侠重开模拟器》，以下简称“本游戏”）。本政策说明本游戏及其广告服务如何处理信息。游戏开发者中心显示的开发者名称为“南城工作室”。本游戏的核心进度保存在您的设备上；广告服务仅在您选择同意后初始化。请在使用前阅读本政策。

一、适用范围与服务

本政策适用于 Android 包名 com.wuxia.restart 的本游戏及其集成的 TapADN（Dirichlet）广告 SDK。本游戏不提供游戏账号注册、第三方登录、社交、云存档或游戏内购买功能。游戏进度、设置和隐私选择保存在设备本地。

二、我们处理的信息

1. 本地游戏数据

本游戏在设备本地保存游戏进度、事件选择与统计、游戏设置以及广告与隐私选择。该等数据由本游戏用于恢复进度和记住您的设置，不会由本游戏上传至自有服务器。删除应用数据或卸载本游戏会删除相应本地数据。

2. 广告服务信息

在您选择“同意个性化广告”或“仅使用非个性化广告”后，本游戏才会初始化 TapADN（Dirichlet）广告 SDK。广告供应方为上海艾得蒽数字科技有限公司及其关联方。为请求、展示、统计和保护广告服务，SDK可能按其隐私政策处理下列信息：

  • 设备基础信息：设备品牌和型号、操作系统版本、屏幕密度与分辨率、语言、时区、CPU及可用存储空间。
  • 设备标识符：Android OAID；在系统版本、SDK配置和相应授权允许时，可能处理 IMEI、Android ID、AAID 或 VAID 等可选标识符。
  • 网络与应用信息：IP 地址、网络类型、Wi-Fi 状态和信号强度、应用包名和版本、应用前后台状态及运行进程信息。
  • 广告与诊断信息：广告请求、展示、点击和转化等交互记录，以及崩溃和性能数据。激励广告请求还会携带当前游戏进程的局内标识、奖励名称和数量，用于奖励校验，不包含您的姓名、手机号或账号。
  • 可选信息：在 Android 权限、SDK版本和请求场景允许时，SDK可能处理粗略或精确位置信息、Wi-Fi 接入点信息、已安装应用列表和传感器信息，用于广告定向、归因、反作弊或广告交互。游戏自身不提供定位、蓝牙或传感器功能。

SDK 会按照其隐私政策及具体广告请求使用相关信息；广告合作方可能接收去标识化或匿名化的必要广告信息，用于广告投放、统计、归因与反作弊。具体处理范围受 SDK 版本、广告请求、设备能力及授权状态影响。TapADN 的隐私政策见：https://ssp.dirichlet.cn/docs/agreement/ 。

3. 个性化广告选择

您可以选择个性化广告或非个性化广告。选择非个性化广告后，广告仍可能展示，但 SDK 不应按个性化推荐方式处理广告；广告服务仍可能处理完成广告请求、展示统计和安全防护所必需的信息。若您选择“不同意广告并继续游戏”，广告 SDK 不会初始化，游戏核心内容仍可使用，但依赖广告的奖励或广告功能不可用。选择会保存在设备本地；清除本游戏数据后可重新选择，清除操作也会删除本地游戏进度。

三、设备权限

最终 Android APK 的合并清单声明了下列权限。网络权限用于广告请求；其余权限由广告 SDK 或 Android 组件声明，按设备系统、SDK功能和具体请求场景使用。游戏核心玩法不需要定位、电话状态、应用列表、安装软件包或蓝牙功能。可选权限被拒绝时，广告可能无法获得相关信息或部分广告功能不可用，但游戏核心玩法不受影响。

权限用途是否为核心玩法所需
INTERNET、ACCESS_NETWORK_STATE连接网络、判断网络状态并请求广告广告需要；离线核心玩法不需要
ACCESS_COARSE_LOCATION、ACCESS_FINE_LOCATIONSDK可选的粗略或精确位置处理，用于广告定向或反作弊否

系统权限仅在 Android 系统允许且相关调用发生时生效。您可以在系统设置中管理可撤回的运行时权限。SDK的权限与数据处理详情以 TapADN 隐私政策为准。

四、信息存储、共享与保护

本游戏的存档与设置保存在您的设备应用空间中；开发者没有自有游戏服务器，不接收或保存这些本地存档。广告请求所需信息由 TapADN 服务及其为提供广告而合作的服务方按各自规则处理和保存。TapADN说明其在中国境内运营中收集和产生的信息存储于中国境内，并在提供服务所需期间保存；更多细节请阅读其隐私政策。

本游戏不会出售您的个人信息。我们不会将本地游戏存档提供给广告供应方。除广告服务所需的 SDK 处理与合作外，未经法律允许或您的单独授权，我们不会向无关第三方提供您的个人信息。我们会采取合理措施保护本地数据和广告接入配置，但设备安全和第三方服务处理仍受设备及对应服务方政策影响。

五、您如何管理信息

您可以通过设备系统清除本游戏数据或卸载游戏，删除本地存档、设置及隐私选择。清除后，本游戏无法恢复这些本地数据。您可拒绝可选系统权限；如需重新选择广告隐私选项，可先清除本游戏数据后重新启动。关于 TapADN 已处理的信息，您也可以按其隐私政策联系其隐私保护负责人：privacy@dirichlet.ai。

六、未成年人保护

本游戏不要求未成年人提交姓名、身份证号码或联系方式。未成年人应在监护人指导下阅读本政策并使用本游戏。TapTap TapPlay 模式的实名与防沉迷由 TapTap 平台按其规则提供；本 APK 未集成游戏内独立的 TapTap 实名防沉迷 SDK。广告 SDK 对未成年人信息的处理以其隐私政策及适用法律为准。

七、政策更新

当游戏功能、SDK、信息处理方式或适用规则发生变化时，我们会更新本政策并在游戏内及 TapTap 政策页面公布。涉及处理目的、信息范围或第三方等重大变化时，我们会按适用规则重新告知并取得必要同意。

八、联系我们

如您对本游戏的信息处理或本政策有疑问，可通过 TapTap 游戏页面联系开发者“南城工作室”。如问题涉及 TapADN SDK，可联系 privacy@dirichlet.ai。我们会在适用法律要求的期限内处理您的请求。
