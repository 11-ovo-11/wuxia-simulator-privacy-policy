《武侠重开模拟器》隐私政策

更新日期：2026年10月10日

生效日期：2026年10月10日

欢迎使用《武侠重开模拟器》（游戏内显示名称为《武侠重开模拟器》，以下简称“本游戏”）。本政策说明本游戏、广告服务和游戏统计服务如何处理信息。游戏开发者中心显示的开发者名称为“南城工作室”。本游戏的核心进度保存在您的设备上；广告与游戏统计服务仅在您同意本次更新后的政策后初始化。请在使用前阅读本政策。

一、适用范围与服务

本政策适用于 Android 包名 com.wuxia.restart 的本游戏及其集成的 TapADN（Dirichlet）广告 SDK 与 TapSDK / TapDB 数据分析服务。本游戏不提供游戏账号注册、第三方登录、社交、云存档或游戏内购买功能。游戏进度、设置和隐私选择保存在设备本地。

二、我们处理的信息

1. 本地游戏数据

本游戏在设备本地保存游戏进度、事件选择与统计、游戏设置以及广告与隐私选择。该等数据由本游戏用于恢复进度和记住您的设置，不会由本游戏上传至自有服务器。删除应用数据或卸载本游戏会删除相应本地数据。

2. 广告服务信息

在您选择“同意并继续”后，本游戏才会初始化 TapADN（Dirichlet）广告 SDK。广告供应方为上海艾得蒽数字科技有限公司及其关联方。为请求、展示、统计和保护广告服务，SDK可能按其隐私政策处理下列信息：

  • 设备基础信息：设备品牌和型号、操作系统版本、屏幕密度与分辨率、语言、时区、CPU及可用存储空间。
  • 设备标识符：Android OAID；在系统版本、SDK配置和相应授权允许时，可能处理 IMEI、Android ID、AAID 或 VAID 等可选标识符。
  • 网络与应用信息：IP 地址、网络类型、Wi-Fi 状态和信号强度、应用包名和版本、应用前后台状态及运行进程信息。
  • 广告与诊断信息：广告请求、展示、点击和转化等交互记录，以及崩溃和性能数据。激励广告请求还会携带当前游戏进程的局内标识、奖励名称和数量，用于奖励校验，不包含您的姓名、手机号或账号。
  • 可选信息：在 Android 权限、SDK版本和请求场景允许时，SDK可能处理粗略或精确位置信息、Wi-Fi 接入点信息、已安装应用列表和传感器信息，用于广告定向、归因、反作弊或广告交互。游戏自身不提供定位、蓝牙或传感器功能。

SDK 会按照其隐私政策及具体广告请求使用相关信息；广告合作方可能接收去标识化或匿名化的必要广告信息，用于广告投放、统计、归因与反作弊。具体处理范围受 SDK 版本、广告请求、设备能力及授权状态影响。TapADN 的隐私政策见：https://ssp.dirichlet.cn/docs/agreement/ 。

3. 广告与统计选择

首次进入以及本次新增聚合广告与统计功能更新后，游戏重新展示政策摘要，只有“同意并继续”与“暂不同意/退出”两个按钮。点击同意后初始化广告与游戏统计服务，广告默认非个性化。拒绝后本次游戏直接退出，不初始化广告及统计服务。接受旧版政策不会自动授权新增聚合广告与统计。清除应用数据后可重新选择，但会删除本地游戏进度；清除本地数据不会自动删除第三方已保存的记录。非个性化广告仍需处理广告展示、奖励核验和安全防护所必需的信息。

4. 游戏统计信息（本次新增）

我们使用易玩（上海）网络科技有限公司提供的 TapSDK / TapDB，在中国区服务中分析活跃设备、游戏流程、平衡性和故障。SDK可能处理设备型号、系统及应用版本、网络状态与IP地址、Android ID 或本地生成并保存的设备标识、启动与会话等信息。本次集成关闭自动内购事件和通过反射采集 OAID，不使用账号登录。

游戏自定义上报限于：轮回标识、年龄及年龄段、基础属性、天赋和结局卡 ID、事件及选项 ID、条件判定结果、战斗 ID/人数/时长/胜负/剩余生命、商店商品 ID/刷新/购买、结局及解锁状态、广告请求/奖励核验/失败阶段/插屏展示关闭等。轮回标识为游戏按本局创建时间生成的标识，不是账号。不上报玩家姓名、联系方式、完整存档、叙事正文或反馈正文；不伪造充值或广告收入。统计需联网，核心游戏进度仍保存在本地。服务方隐私政策：TapSDK 隐私政策；数据处理说明：TapSDK 合规使用说明。

5. 聚合广告供应方（本次新增）

属性分配 +5 使用 TapADN 直连接口；第三结局卡槽位在平台开通后使用 TapADN 聚合接口。聚合通道只在您触发第三槽位广告时初始化，未开通时不请求，可能由穿山甲或优量汇提供广告。

  • 穿山甲广告 SDK，服务方：北京巨量引擎网络技术有限公司。为广告展示、监测归因、统计和反作弊，SDK可能处理设备品牌/型号、系统及应用信息、屏幕、语言、CPU与存储信息、SIM卡及运营商信息、OAID/Android ID、网络/IP、广告展示点击转化和崩溃性能数据；根据系统授权与实际配置，还可能处理其他设备标识、应用列表、位置/Wi-Fi接入点及传感器信息。穿山甲隐私政策。
  • 优量汇 SDK，服务方：深圳市腾讯计算机系统有限公司。为广告投放、归因、监测和反作弊，SDK可能处理设备制造商/型号、系统、屏幕/时区、IP/网络/运营商、OAID、应用包名/版本/进程/状态、广告交互和诊断数据；根据系统授权与实际配置，还可能处理 Android ID、应用列表/安装信息和位置/Wi-Fi信息。优量汇隐私政策。

聚合接入关闭可选位置、电话状态、Wi-Fi、MAC/BSSID/SSID、传感器、外部存储及应用列表采集开关，但限制范围受三方实际支持的接口影响，不承诺关闭所有必要设备信息处理。供应方具体信息范围、权限、目的与处理规则请同时阅读 TapADN 第三方清单及上述供应方政策。旧版同意不会自动授权新增供应方，更新后需要重新同意版本 3 政策。

三、设备权限

0.1.23 版最终 Android APK 的合并清单只保留 INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE、VIBRATE、WAKE_LOCK 以及穿山甲组件的签名级内部通信权限，用于联网广告、网络状态判断、广告播放和必要的广告组件运行。本游戏不声明、也不申请电话状态、精确或粗略位置、蓝牙、外部存储、安装软件包或应用列表权限。

因此，首次启动和广告初始化不会提前弹出电话或位置权限对话框；本游戏也没有需要这些权限的功能。TapADN 及广告供应方可能按照各自公开政策处理广告请求所需的设备、网络和标识信息，具体范围以其政策为准，但本应用不会为此向用户申请上述运行时权限。

四、信息存储、共享与保护

本游戏的存档与设置保存在您的设备应用空间中；开发者没有自有游戏服务器，不接收或保存完整本地存档；上述统计事件由 TapDB 中国区服务保存，开发者可在后台查看与分析。统计与设备数据按服务所需期间及服务方政策保存。广告请求所需信息由 TapADN 服务及其为提供广告而合作的服务方按各自规则处理和保存。TapADN说明其在中国境内运营中收集和产生的信息存储于中国境内，并在提供服务所需期间保存；更多细节请阅读其隐私政策。

本游戏不会出售您的个人信息。我们不会将本地游戏存档提供给广告供应方。除本政策说明的广告与统计服务处理外，未经法律允许或您的单独授权，我们不会向无关第三方提供您的个人信息。我们会采取合理措施保护本地数据和广告接入配置，但设备安全和第三方服务处理仍受设备及对应服务方政策影响。

五、您如何管理信息

您可以通过设备系统清除本游戏数据或卸载游戏，删除本地存档、设置及隐私选择。清除后，本游戏无法恢复这些本地数据。您可拒绝可选系统权限；如需重新选择广告隐私选项，可先清除本游戏数据后重新启动。清除数据、卸载或拒绝政策不会自动删除已经上报的统计记录。如需查询、复制或删除可识别的反馈与统计信息，请联系开发者邮箱 1084144008@qq.com，我们会协助核实和处理，并根据需要联系 TapDB 服务方。关于 TapADN 已处理的信息，您也可以按其隐私政策联系其隐私保护负责人：privacy@dirichlet.ai。

六、未成年人保护

本游戏不要求未成年人提交姓名、身份证号码或联系方式。未成年人应在监护人指导下阅读本政策并使用本游戏。TapTap TapPlay 模式的实名与防沉迷由 TapTap 平台按其规则提供；本 APK 未集成游戏内独立的 TapTap 实名防沉迷 SDK。广告 SDK 对未成年人信息的处理以其隐私政策及适用法律为准。

当游戏功能、SDK、信息处理方式或适用规则发生变化时，我们会更新本政策并在游戏内及 TapTap 政策页面公布。涉及处理目的、信息范围或第三方等重大变化时，我们会按适用规则重新告知并取得必要同意。
